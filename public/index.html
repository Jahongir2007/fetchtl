fetchtl

A futuristic HTML attribute engine that turns your HTML into a reactive API-powered UI — with zero JavaScript.

GitHub → Documentation

🚀 Features

Frontend Features

  • $get — load data from any API into HTML
  • $post / $put / $delete / $patch — submit forms automatically
  • $poll — auto-refresh sections
  • $realtime — Server-Sent Events (SSE) support
  • $send-on — trigger on click, input, submit
  • $single-fetch — throttle repeated requests
  • Built-in template engine (e.g. $name → replaced by JSON value)

Backend Features

  • $.sync(req.body) — syncing req.body for making backend DOM
  • $.input("#age").val() — getting value by ID in backend after sending with $post/$put/$delete/$patch
  • $.input(".email").val() — getting value by class in backend after sending with $post/$put/$delete/$patch
  • $.input("username").val() — getting value by name in backend after sending with $post/$put/$delete/$patch
  • $.input("#age").val(18) — setting data

npm install fetchtl

💡 Example Usage

<form $post="/api/login" $send-on="submit" $single-fetch="true" $reload="false">
  <input name="email" placeholder="Email" />
  <input name="password" type="password" placeholder="Password" />
  <button type="submit">Login</button>
</form>
